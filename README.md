# Road to Prime

Личное приложение-календарь задач. Работает как PWA: открывается на весь экран, ставится на домашний экран iPhone и в Dock на Mac, работает без интернета.

- Кабаны (большие задачи), стейки (их шаги), крысы (мелкие неприятные дела), сферы с прогрессом.
- Таймер на 5 минут и помодоро 30/5.
- Помощник: пёс Шагыч.
- Данные хранятся на устройстве и синхронизируются через приватный Gist в твоём аккаунте GitHub (токен с правом `gist`, хранится только на устройстве).

В репозитории нет личных данных, только код.

## Виджет для iPhone

Скрипт `widget/road-to-prime-widget.js` для бесплатного приложения Scriptable показывает «Сегодня 2 из 5», серию дней, следующие дела и Шагыча. Он читает данные из твоего закрытого Gist (тот же токен, что в приложении) и ничего не записывает. Инструкция в начале файла.
